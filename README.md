The code: mse_bound_verify_case_I.py is for the first task: compare the empirical MSE under iid Gaussian kernel with the theoretical upper bound. 

The code: IID_ORF_mse_comp.py is for the second task: compare the empirical MSE performance under the iid Gaussian kernel and the orthogonal random ensemble kernel

The code: diff_RF_comp.py is for the third task: we compare the empirical MSE under the iid Gaussian, iid Rademacher, dense ORF, and structured ORF kernels

The code: diff_ORF_time_comp is for the last task: we compare the setup time and the online execution time of the dense ORF and the structured ORF kernels
